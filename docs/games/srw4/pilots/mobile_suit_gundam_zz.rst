海适应是A，但是机动战士系没有机体可以发挥这个优点，顶多把海C的机体冲到海B，而且本作水战地图实在不多。用地图武器练级之后補給这个精神很有用。

第四次S中增加了回避。シールド防御从2级提升到6级。
