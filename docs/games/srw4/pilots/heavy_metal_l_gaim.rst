.. _srw4_pilot_lilith_fau_commentBegin:

被囚禁于马戏团时被达巴所救，加入同伴行列。曾参战《EX》的朗德·贝尔成员们常将其误认为\ :ref:`チャム・ファウ <srw4_pilot_chum_huau>`\ (查姆·法乌) 。与查姆的见面事件值得一看.但此后便再无交集。

能获得必中·幸运属性，是擅长地图武器的强力战友。本作《ELGAYM》的驾驶员皆具备热血属性，若在中盘后巧妙组合，可实现等级飞跃式提升。但因其始终与某位驾驶员绑定，不同于《DANBAIN》的妖精们，无法通过漏洞将兜甲儿或主角获得的经验值转移给莉莉丝。

在《第4次S》中，同声优配音的查姆拥有语音，唯独莉莉丝未获配音，战斗中亦无台词。

:doc:`謎の訪問者 <../walkthrough/02a_enigmatic_visitors_fast>`\ /\ :doc:`ダハ=マイロド <../walkthrough/05b_daba_my_lord>`\ 登场

必中幸运激励都是很强力的精神。但是重战机系只有这么一个妖精。所以是抢手货，在用地图武器轰自己人还有经验值的版本不怕那些等级太高的机动战士打不到。不知何故，キリマンジャロの嵐这一话中ブレックス准将的机体不断成为她的幸运的目标，即使眼镜厂修正了击落自军可以获得经验的\ :doc:`../mechanics/bug`\ ，击落盟军似乎仍然可以获得资金和经验。

因为和チャム・ファウ配音演员是一个人的原因，初见面有特殊剧情。第四次S中チャム・ファウ加入了语音，不知为何她没有。
