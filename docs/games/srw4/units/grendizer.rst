.. _srw4_unit_marine_spacer_commentBegin:

不知为何在完全没有台词的情况下出现在格纳库中，如果玩家不检视机体，可能根本不会注意到。

潜水斯陪沙是对海作战机体，武器虽然账面数值高，甚至高于\ :ref:`マジンガーZ <srw4_unit_mazinger_z>`\  (魔神Z)除胸口火焰之外的所有其他武器，但是对于海洋之外的地形的敌人会比较弱。

如果选择承认恋人，那么第五话会比较活跃（不过也就甲児的海适应能看）。对空适应是B，在MS普遍陆地适应为B时具有同等竞争力。所以可以用沙也加或者波士开魔神Z，而甲児开本机来提高战力。

第八话战场之爱之后就可以当ボス的重装探宝机了（ボスボロット本来作用也不大）。虽然甲児仍然可以用它，但是武器的地形适应和残弹数量是个巨大的问题。

尽管可以和\ :ref:`グレンダイザー <srw4_unit_grendizer>`\ (古连泰沙)合体来练魔神系机师，但是一般和古连泰沙合体都是让他们去换乘ダブルスペイザー和ドリルスパイザー，后期没有什么敌人会跑到海里去，对海用的古连泰沙形态基本就是个废物，所以没有改造价值。

.. _srw4_unit_drill_spider_commentBegin:

钻地斯陪沙在14话由玛丽亚驾驶登场。无消耗的大招很少见，而且合体后也能使用，后期分队之前应该让牧場ひかる切换到它上面，这样ダブルスペイザー可以在经常打到弹尽粮绝的オルドナ＝ポセイダル这一话中和グレートマジンガー起作为影响战局的消耗低的超级系机体。

虽然对空适应是B，但是武器威力强劲，可以打出灵格斯或者超级高达级别的伤害。考虑到后期ダブルスペイザー主要和本机合体，提前改造一下钻头攻击和火花轰炸，在中期之前独立作战亦为不可。

大招钻头攻击虽然在动画上看是格斗武器，但是实为一格射击武器，使用时不受本机移动类型限制，对陆地和海中敌人也可以使用。然而本作驾驶员数值采用近/远区分，而非格斗/射击，以至于远程类型的机师，例如玛丽亚和沙也加等，可能使用火花轰炸造成的伤害会更高。

第四次中空中和宇宙适应都提升到了A。但是因为驾驶员的原因，导致玛丽亚驾驶时对空适应仍然为B。

.. _srw4_unit_grendizer_commentBegin:

弗里德星制造的超级机器人，可与支援的太空战斗机对接合体。但是原作设定是背部未配备飞行装置，靠跳跃能力对付空中敌人，而不是像本作一样可以自行浮空。如果罗莎米娅在抢夺机体事件时无可用机体，会炸毁本机和\ :ref:`Ζガンダム <srw4_unit_z_gundam>`\ (Z高达)逃离。

能源消耗太大，如果不合体的话有续航问题，反重力风暴和太空雷霆都太耗EN了。虽然本作可以飞空，然而对空适应是B，不合体的话攻防要下降一档（即使变形成飞机形态也一样）。铁壁+必中无双战术仍然有效。魔神系唯一宇宙A级机体，后期比较强劲。

改造方面，建议集中于太空雷霆，小兵用双刃或者钻头太空机的钻头攻击。

因为无法更换驾驶员，不能像超级高达那样同时培养两个机师。在培养其他机师时，杜克的等级也会被刷得很高，尤其是有幸运的玛丽亚和沙也加，攻击力略差不是什么大问题。

第四次S中除了装甲提升100之外，地形适应也从空B升级到空A，以及海洋适应从D增加到B。杜克自己的适应是全A所以这个升级是有意义的。对地面适应也成为了A，更方便降落获得地形补正。火力也得到明显加强，即使有ダブルハーケン的增强,单独作战时续航仍然很差。

另外，ダブルハーケン不知为何被设定成为了一格射击武器，对深海中的敌人也可使用。
