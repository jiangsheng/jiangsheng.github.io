====================================
ダンバイン/ダンバインOVA登场机体
====================================

括号内为PS版变动。地形补正(→)为用默认驾驶员的地形适应和机体的移动类型修正之后的数据。偏差值表示排名位置，均值为50。


.. contents:: 
   :depth: 2
   :local:
   :backlinks: none

.. _srw4_units_dunbine_commentBegin:

本作起奥拉战士(AB)需圣战士技能才能使用奥拉斩，但作为补偿被设定为零消耗武器，虽入手初期略显冷门，经改造后却能展现违规级强度。第四次S中奥拉斩改为EN消耗武器。

.. _srw4_units_dunbine_commentEnd:

--------
我军机体
--------
.. _srw4_units_dunbine_own_commentBegin:

因为具有高回避和分身能力，奥拉系机体是我军的王牌，在游戏后期之前，作为主力坦克活跃于战场。

虽然本系机体宇宙适应较差，但是真正宇宙作战只有两次，问题不大。后期的问题主要是限界255的上限限制，虽然以S的大小以及分身能力可以应付，但在敌人数量过多时仍然生存能力堪忧，这个角色才逐渐让位于超级系的机器人。但是高HP的单位通常运动性和命中率低下，以至于在敌方回合防御效果更佳，不像本系机体一样可以用反击削弱敌人，所以这是一个降级。

注意后期会统一分去B队，以至于A队陷入苦战，所以应预先培养超级系肉盾以作替补。

奥拉斩改造过于昂贵，一般只能改满两到三台机器的奥拉斩，所以投入资金至过多奥拉机器属于浪费。

.. _srw4_unit_bilvine_commentBegin:


由于奥拉转换器出现故障正在维修，该机体一度缺席战场。期间被A国夺取，并在地面路线第24话《提坦斯的崛起》中作为艾伦的驾驶机以敌方身份登场。不过由于其HP和装甲与在我方时相同且未经改造，实力并不突出，建议配合精神指令轻松击落。紧接着在次话《超级杰利尔》中，翔于增援时登机，终于正式加入我方阵营。这也意味着翔被迫从改造好的雪拜因或兹瓦乌斯转驾未经改装的\ :ref:`ビルバイン <srw4_unit_bilvine>`\ （比尔拜因），战斗力有所下降。更糟的是，此时若未大幅提升等级，则玛贝尔尚未习得圣战士技能。不过这比后期被迫转乘GP-03S沦为战力废柴的科还是要强得多……

HP值较前作大幅降低，未经改造时稍显吃力。此外前述的塞巴因或兹瓦乌斯获取更早，除射程外几乎全面超越比尔巴因的性能，因此若未计划培养除翔之外的奥拉机师，比尔巴因常被闲置仓库的情况并不少见。

第四次S中奥拉斩改为消耗EN，装甲值下降80点，且作为全AB机体共通的削弱调整，奥拉斩改为消耗EN的武器，但即便如此依然强得离谱。同样容易被隐藏机体抢走常规出场机会的特性也未改变。若采用单机突击战术，为节省EN，可考虑把武器改造的重点从光束剑改为灵气剑。奥拉斩的改造费非常贵，以至于可能最多只能使用三台，有时候甚至是两台奥拉战士。第四次走ゴラオン路线的话，可以拿到一台武器改造过的ライネック，所以是否改造它是个难题。

因为远程武器强，可以让玛贝露・弗洛森驾驶，充分发挥其远攻击优势。

在16话中，雪拜因和シルキー同时加入。和ズワウス、ダンバイン三选一。只能进行近战，但是威力强大。

虽装甲较兹瓦乌斯稍薄，但在奥拉战士更需要的能力——运动性与移动力方面占据优势。然而本作限界上限仅255，后期生存能力略逊于兹瓦乌斯。不过两机均具备战斗至终局的能力，单纯根据个人喜好选择亦无不可。

相较于\ :ref:`ビルバイン <srw4_unit_bilvine>`\ （比尔拜因），这台机体更极致地体现了奥拉巴托拉核心价值——"高机动性"。虽无射击武器，但本作敌方单位的AI设定是命中率低下时会主动切换至巴尔干炮这类命中修正高的近战武器。因此只要让回避率高的翔驾驶员坐镇前线，敌方单位就会主动靠近。这使得射程的缺陷几乎不构成实质影响。不过远距离的劣势并非完全丧失，如果敌人完全缺乏近战能力，若不想陷入进退维谷的窘境，建议启用比尔拜因。

若让翔驾驶本机，其尚可的射击攻击力将沦为废属性，因此相较之下，格斗能力与翔相当而射击偏低的嘉拉莉亚・纽姆希反而更契合。

获取条件需将翔移动至特定地图的特定位置，但游戏中毫无提示（因附近埋藏强化零件，探索时可大致推测位置），且该点远离部队展开点，更与敌军部队方向完全相反，不知情者基本无法获取（勉强算是提示的线索是该地图查姆·法乌无法出击）。

第四次S中奥拉斩改为消耗EN。同时因为比尔拜因装甲值降低，使其耐久力也得以超越比尔拜因。
