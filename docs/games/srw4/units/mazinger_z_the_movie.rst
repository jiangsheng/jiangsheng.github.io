.. _srw4_unit_dragonsaurus_commentBegin:

笔直冲向名古屋，优先考虑移动而非攻击。

开始的时候只有一半HP,20000，加上每回合的10%HP回复，在海里比较难打。ドラゴノザウルス的主要弱点是对空武器超声波的存量太少，几回合后就会用完，所以空中部队可以自由攻击它。原作中可以飞的，如果真的实现这一点的话，这一话不知道怎么打。
