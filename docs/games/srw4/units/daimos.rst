.. _srw4_unit_daimos_commentBegin:

戴莫斯是开局之后加入部队的第一个超级机器人。当然也是最弱的一个。装甲比较差，所以虽然可以飞，但是只有在陆地上才能发挥最大能力（默认移动方式是飞行），所以开战之后还是陆行吧。

本作近身格斗武器的地形适应是看敌方所在，所以用必殺烈風正拳突き改攻击空中敌人的时候攻防能力要下降两成，用盖塔的烈日光弹攻击地面敌人的时候也会吃这个亏。不过必殺烈風正拳突き居然是近身射击武器，没有这个惩罚，大概算个bug。

戴莫斯远程的武器攻击低残弹少。近身的武器虽然很多，但是重复性太高，除了大招之外，就连需要涨气力之后才能用的武器攻击力也才一千出头，基本都没有什么改造价值，除了暴击率+30的双竜剣。作为单座机器人，缺乏幸运和加速，大招也不能在宇宙中使用，后期出场价值较低。必杀技消耗70EN，虽然不算高，但是相比雷登和泰坦3来说仍为耗油大户，更不要说跟盖塔相比。另外，因为单座的原因，缺乏加速，机动性欠佳，难以从射程外加速切入发动猛烈攻势。唯一可取之处，大概是因为加入较早，改造段数较高而已。

走超级系路线的话，30话会追加几个实用武器，其中必殺烈風正拳突き改EN消耗不高比较实用。走真实系路线的话，因为没有追加武器，这机体并不实用。会在宇宙中出战两话，大招在宇宙里都不能用基本就让这台机器人废掉了。因为有强制剧情登场原因，超级系路线还是要对本机改造一下以避免苦战。如欲挑战自己，完全不改造，等到30话实用武器入手后再改造也是可行之策。在真实系路线则因缺乏追加武器，而且缺乏在低气力下可用的使用武器，封存也为不可。

第四次S里面武器做了强化，但是仍然不能在宇宙里用大招。地形适应升级成空A海C，但是一矢仍然是空B，造成对空能力无变化。

本作没有强制入海的地图，在有空B的场合，无论海C还是海D，海洋都是不会主动进入的地形。地形适应的设定更改可以说是基本没有实际意义。不过因为必殺烈風正拳突き不知为何被判定为射击武器，在对海洋敌人时不会受到地形适应的惩罚，所以是个例外（不要被动画骗了）。
