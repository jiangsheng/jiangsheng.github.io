==================
エルガイム登场机体
==================

括号内为PS版变动。地形补正(→)为用默认驾驶员的地形适应和机体的移动类型修正之后的数据。偏差值表示排名位置，均值为50。


.. contents:: 
   :depth: 2
   :local:
   :backlinks: none

.. _srw4_units_heavy_metal_l_gaim_commentBegin:

和优秀的人物对应的，重战机系机体通常比较弱。ビームコート只在初期比较让人困扰。后期有了地图武器那更加不是问题。但是地形适应优秀，又有光线防御，后期潜力相当可观。

.. _srw4_units_heavy_metal_l_gaim_commentEnd:

--------
我军机体
--------
.. _srw4_units_heavy_metal_l_gaim_own_commentBegin:

由于エルガイム Mk-II性能过于出色，外加本系妖精莉莉丝有幸运，以至于本系机师很容易用地图武器刷得很高，在回归原有机体之后，用很弱的武器也能打出不错的伤害，机体性能平庸一点也瑕不掩瑜，所以除了需要改造限界和地图武器之外，可以放心把资金投入其他机体的改造。

有光线防御，因为机师技量高很容易出会心一击，武器攻击力比账面数字高，甚至具备移动后可对空的远程武器，早期很强力。

机师集中出得慢，可以考虑装强化物品来增加回避能力。超级系走地上路线的话可以改造一下。

真实系后期走宇宙路线要和加入时有两段改造以至于性能更好的\ :ref:`カルバリーテンプル <srw4_unit_calvary_temple>`\  (灾厄神殿)二选一。艾尔盖姆的优点是有移动后可攻击的武器，而灾厄神殿的优点则是入手的时候改造了两段，性能更好。

和其他本系机体一样，第四次S中提升了动力发射器的威力，但是减少了残弹数量。S地雷的威力也有所上升。

迪扎德后期会被废弃，不建议改造。在宇宙路线会返还5000资金，但是地面路线会直接丢弃（没有容量限制的第四次S也是如此），不会返还，建议在进入地面路线之前事先手动废弃。

生存能力靠强化部件和光线防御。陆A造成攻防能力比很多初期机动战士机体要强。
